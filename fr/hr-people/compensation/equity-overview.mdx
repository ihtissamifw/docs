L'équité est une partie importante de la rémunération totale pour la plupart des rôles. Cette page explique les bases—pour des détails personnalisés, consultez votre accord d'attribution ou contactez les RH.

## Types d'attribution

Nous émettons des actions sous deux formes selon le stade de l'entreprise et le niveau de l'employé :

**Stock-options (ISO / NSO)** — Le droit d'acheter des actions au prix d'exercice fixé à la date d'attribution. Les options ont de la valeur si la juste valeur marchande de l'entreprise dépasse votre prix d'exercice.

**RSU (Restricted Stock Units)** — Une promesse d'actions livrées lors de l'acquisition. Les RSU ont de la valeur tant que l'entreprise a une valeur, ce qui les rend moins risquées que les options.

Votre lettre d'offre précise le type que vous avez reçu.

## Calendrier d'acquisition

L'acquisition standard est de **4 ans avec une falaise d'1 an** :

- Aucune action acquise avant votre 1er anniversaire
- 25 % de votre attribution acquis à la date de falaise
- Les 75 % restants acquis mensuellement sur les 36 mois suivants

Les attributions de rafraîchissement pour les employés en poste s'acquièrent selon le même calendrier mensuel sans falaise.

## Exercer les options

Les options doivent être exercées pour être converties en actions. Vous avez une fenêtre pour exercer :

- Pendant l'emploi : à tout moment après l'acquisition
- Après le départ : généralement 90 jours à partir de votre dernier jour (vérifiez votre accord d'attribution)

Les implications fiscales varient selon le type d'option (ISO vs NSO). Parlez à un conseiller fiscal avant d'exercer.

## Événements d'équité

Lors d'un événement de liquidité (IPO, acquisition), les actions acquises deviennent négociables ou sont converties en espèces. Les actions non acquises sont généralement soumises à des clauses d'accélération dans les scénarios d'acquisition—vérifiez votre accord.
